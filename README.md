# ScriptForge

### ScriptForge — це програма для створення професійних сценаріїв для відео. Вона дозволяє зручно писати, редагувати та структурувати сценарії для YouTube, TikTok, рекламних роликів та інших відеопроєктів.
У програмі доступний потужний текстовий редактор з можливістю змінювати шрифт, розмір тексту, робити текст жирним, курсивним, підкресленим та використовувати інші інструменти форматування.
Для швидкого створення структури сценарію передбачені спеціальні кнопки:

- A-Roll — додає заголовок секції A-Roll та дозволяє описати основний відеоряд.
- B-Roll — додає заголовок секції B-Roll для додаткових кадрів і вставок.
- Motion — додає заголовок секції Motion для опису анімацій, переходів та візуальних ефектів.

 Коли користувач виділяє текст і натискає одну з цих кнопок, програма автоматично створює відповідний заголовок і переносить вибраний текст до цієї секції. 
 
 ### ScriptForge допомагає авторам контенту швидко організовувати свої ідеї, планувати зйомки та створювати зрозумілі сценарії для всієї команди.
